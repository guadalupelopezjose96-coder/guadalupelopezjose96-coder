# José Emanuel Guadalupe López (`guadalupelopezjose96-coder`)

Arquitectura de software de alto rendimiento, seguridad criptográfica y desarrollo de sistemas en **Rust**, **C** y **Python** para [fourphonix.com](https://fourphonix.com).

## Ecosistema y Proyectos Principales
* **Aura Tetrax (`aura-tetrax` / `aura-tetrax-core`)**: Núcleos de procesamiento y concurrencia en Rust.
* **Infraestructura Web (`Axum-Tokio`)**: Servicios asíncronos de red de baja latencia.
* **Compilación y Seguridad (`Hexakis` / `fourphonix-core-jegl` / `Aura-Intel-Elite-Core`)**: Automatización, SAST y auditoría forense.
* **Acceso Universal (`LEY-ADT-FESM-ACCESO-UNIVERSAL`)**: Herramientas públicas y cumplimiento normativo en Python.

## Cumplimiento Legal y Seguridad
Todos los repositorios bajo esta cuenta aplican verificación criptográfica GPG, análisis estático automatizado (CI/CD) y auditoría estricta de licencias (SPDX / GPL v2.0 / MIT).
